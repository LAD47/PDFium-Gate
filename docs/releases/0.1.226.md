# PDFium Gate 0.1.226

0.1.226 is a release-infrastructure and documentation cleanup for the Obsidian Community Plugins distribution path. It does not intentionally introduce a new PDFium Gate feature set.

## Highlights

- Community Plugins is now the documented normal installation and update path.
- The GitHub publishing workflow is renamed to **Publish Community Plugin release**.
- Normal Community releases are ordinary GitHub Releases, not GitHub prereleases.
- Release publishing is manual-only and requires the matching frozen `archive/<version>` branch before publication.
- BRAT is removed from the active release/install workflow and remains historical only.
- The root README is reorganized for ordinary Community Plugins users.
- Public manifest author metadata is now `LAD47`.
- npm dependencies are locked with `package-lock.json`.
- CI uses `npm ci` so generated runtime is built from the same dependency tree locally and on GitHub.
- The generated runtime was rebuilt against the locked dependency tree and passed the complete repository verification pipeline.

## Practical verification carried forward into this release

The final Email Import / Archive Import behaviors that were still listed as pending after 0.1.225 were practically confirmed before preparing 0.1.226:

- flat Email ZIP attachment layout;
- correct links from the generated email PDF to extracted PDFs;
- retained ZIP provenance in DocumentInfo;
- external ZIP detection and import when a ZIP is copied into the Vault through the operating-system file manager and focus returns to Obsidian.

## Compatibility

- Obsidian minimum version: **1.13.7**
- Desktop only.
- Current practical baseline: Windows 11 / Obsidian 1.13.7 / Electron 43.3.0.

## Verification

Before release preparation, the complete local repository verification pipeline passed with the locked dependency tree:

```text
npm ci
npm run check
```

Production dependencies also reported no known vulnerabilities with:

```text
npm audit --omit=dev
```

## Distribution

PDFium Gate is distributed to ordinary users through **Obsidian Community Plugins**.

The GitHub Release must contain:

- `main.js`
- `manifest.json`
- `styles.css`

The exact approved release is frozen under `archive/0.1.226` before the Community release workflow is run.
