# PDFium Gate 0.1.225

0.1.225 is a development/test release focused on Email Import, Archive Import, attachment integrity and safer document-record handling.

## Highlights

- Import EML and MSG messages into normal PDFium Gate PDFs.
- Exact-source SHA-256 duplicate detection for imported email.
- Complete attachment list rendered into the generated email PDF.
- Direct clickable links from the generated email PDF to imported attachments.
- One localized sibling attachment folder per imported email.
  - Norwegian Bokmål: `… Vedlegg/`
  - English: `… Attachments/`
  - equivalent labels for the other supported UI languages.
- Direct attachments and members from multiple ZIP attachments share the same email attachment folder.
- ZIP members from email are flattened to filenames; the original archive member path remains technical provenance.
- Filename collisions are resolved deterministically with suffixes such as ` (2)`.
- ZIP is treated as a transport container, not a normal persistent email attachment document.
- Successful email imports do not require the original EML/MSG to remain in the Vault.
- Exact original EML/MSG retention remains available as an advanced opt-in and is off by default.
- Attachment import is transactional with byte read-back verification and rollback.
- PDF auto-registration races are handled safely and transaction-owned records are rolled back on failure.
- Generic manual Archive Import supports ZIP safety preflight, preserved archive directory structure, PDF registration and Archive Relationships.
- Successful manual ZIP import deletes the source ZIP only after the complete transaction succeeds.
- Failed manual ZIP import rolls back transaction-owned output and offers **Keep ZIP** / **Delete ZIP**.
- ZIP files copied through the operating-system file manager are detected through startup/focus reconciliation.
- DocumentInfo can show archive provenance and related files without requiring a live source ZIP path.
- Missing-document and document-record handling received additional fail-closed fixes and regression coverage.

## Compatibility

- Obsidian minimum version: **1.13.7**
- Desktop only.
- Most practical verification for this release was performed on Windows 11 / Obsidian 1.13.7 / Electron 43.3.0.

## Practical verification completed

The development branch has practical confirmation for:

- automatic EML import;
- source staging cleanup after successful verified import;
- direct PDF attachments;
- multiple ZIP attachments in one email;
- one localized email attachment folder;
- source ZIP removal for successful email imports;
- complete attachment lists in generated email PDFs;
- direct opening of imported PDF attachments;
- DocumentInfo provenance for PDFs originating inside ZIP attachments;
- localized Norwegian Bokmål attachment-folder naming.

## Remaining test focus for broader users

0.1.225 is still pre-release software. Broader testing is specifically useful for:

- unusual real-world EML/MSG structures and encodings;
- large/mixed ZIP attachments;
- manual ZIP arrival through Windows/macOS/Linux file managers;
- failed/corrupt/password-protected ZIP handling;
- rename/move behavior for imported non-PDF attachments;
- macOS and Linux runtime differences;
- future Obsidian/Electron/Chromium compatibility.

Back up the Vault before testing.
