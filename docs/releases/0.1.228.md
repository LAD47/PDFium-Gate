# 0.1.228 release candidate

Prepared on 2026-10-13 on `feature/0.1.228-email-bundles`. This is a candidate, not a published release.

## Changes

- New EML/MSG imports use one self-contained `YYYY-MM-DD - EPOST- Subject` folder with a namesake parent PDF, direct attachments and flattened ZIP members. Collisions apply the same suffix to folder and PDF. Existing imports retain their paths; manual ZIP import preserves archive directories.
- Email staging arrival reconciliation handles create, startup and focus through the serialized queue; first-run inventory prevents historical mass import and unchanged failed sources do not cause repeated prompts.
- Archive/parent-link read-back handles bracket-containing member names. Attachment rollback removes only attempt-owned files/records and reports failures.
- Author and Published online metadata fields use a controlled one-time schema upgrade, retain existing identities and disabled states, and preserve deletion after the migration marker is written.
- Factory labels follow UI language while user labels remain unchanged. HTTP(S) URLs are clickable, changed invalid URLs produce localized validation errors and unchanged legacy URLs survive edits to other fields. Register Enter/Escape behavior remains covered.

The schema version remains 1 but accepts the new `migrations.author_source_url_v1` extension. Older 0.1.227 contracts reject `migrations`. Returning to **0.1.227 after schema migration is not guaranteed** and may require a compatible schema backup; preserve subsequent schema edits separately. Synthetic compatible-schema restoration passed; whole-plugin downgrade is untested. Process crashes, simultaneous faults and recovery failure are outside the verified scope.
